# افزونه Daily Bale Post

ارسال خودکار روزانه‌ی یک **محصول ووکامرس، نوشته، برگه یا نوع پست سفارشی** (از جمله نوع پست‌های ساخته‌شده با **جت‌انجین**) به کانال **بله** و **تلگرام**، همراه با عکس، قیمت (و تخفیف)، متن و دکمه‌ی مشاهده. متن پیام هر کانال را خودتان می‌نویسید و تمام تنظیمات از پنل مدیریت وردپرس قابل کنترل است.

**نسخه ۴.۲.۰** — تلگرام، هر نوع محتوا، و متن پیام سفارشی هر کانال.

افزونه به‌صورت پیش‌فرض **هیچ برندی ندارد**. اگر آژانس یا فروشنده‌اید، نام و لوگوی خودتان با یک پروفایل پیکربندی اضافه می‌شود، بدون دست‌زدن به کد. [بخش برندینگ](#برندینگ-اختیاری) را ببینید.

---

## دو مدل بسته، یک کد

با `php build.php` دو بسته‌ی نصب ساخته می‌شود:

| بسته | توضیح |
|---|---|
| `dist/daily-bale-post-4.2.0.zip` | **تمیز** — بدون هیچ برندی؛ نه بنر، نه لوگو، نه لینک. |
| `dist/daily-bale-post-4.2.0-<brand>.zip` | **برنددار** — به‌ازای هر پروفایل موجود در `branding/`، آماده‌ی نصب روی سایت مشتری. |

هر دو از یک کد ساخته می‌شوند، پس لازم نیست دو نسخه‌ی موازی نگه‌داری و با هم هماهنگ شود.

---

## چه چیزی در نسخه ۴.۲ اضافه شد

### ارسال به تلگرام
- همان پست روزانه، هم‌زمان به کانال بله و کانال تلگرام می‌رود؛ هر کدام را می‌توان جدا خاموش یا روشن کرد.
- کلاینت پایه‌ی `DSB_Messenger` با قرارداد مشترک Bot API و یک کلاس جدا برای هر پیام‌رسان؛ پس زنجیره‌ی مقاوم ارسال تصویر، کوتاه‌سازی کپشن، خنثی‌سازی مارک‌داون و تلاش مجدد، برای تلگرام هم اجرا می‌شود.
- فیلد **نشانی پراکسی API** برای سرورهایی که به `api.telegram.org` دسترسی ندارند (یا فیلتر `dsb_telegram_endpoint`).
- ارسال نیمه‌موفق: اگر یک کانال جواب بدهد و دیگری نه، پست روی کانال سالم می‌رود، خطای کانال دیگر جداگانه در تاریخچه ثبت می‌شود و پست آن روز سوخته حساب نمی‌شود.

### هر نوع محتوا
- فیلد **نوع محتوا**: محصول ووکامرس، نوشته، برگه یا هر نوع پست سفارشی. چند مورد را هم می‌توان انتخاب کرد؛ هر روز از میان همه یکی تصادفی می‌رود.
- نوع پست‌های ساخته‌شده با **جت‌انجین (JetEngine)** یا هر افزونه‌ی دیگر، چون در وردپرس ثبت می‌شوند خودشان در این فهرست می‌آیند.
- فیلد **دسته‌بندی و ترم**: طبقه‌بندی‌های همان نوع محتواها، گروه‌بندی‌شده و با رابطه‌ی «یا».
- بخش قیمت فقط برای محصول ساخته می‌شود؛ برای نوشته، چکیده (و اگر نبود ابتدای متن) می‌رود.
- فیلتر موجودی فقط روی محصول اثر دارد؛ در حالت ترکیبی نوشته‌ها حذف نمی‌شوند.

### متن پیام و تنظیمات مستقل هر کانال
- برای هر کانال یک **قالب متن جدا** با ۱۵ شورت‌کد و بخش شرطی.
- توکن، آیدی کانال، حالت ارسال تصویر، نمایش و متن دکمه — همه برای بله و تلگرام جدا.
- **کانال خاموش کامل از مدار خارج می‌شود**: هیچ کلاینتی ساخته نمی‌شود، پس نه پست خودکار می‌رود، نه ارسال تستی، نه حتی یک درخواست به سرورش.
- **تست اتصال** با `getMe`، **پیش‌نمایش متن** بدون ارسال، و **ارسال تستی تک‌کاناله**؛ هر سه قبل از اجرا تنظیمات صفحه را ذخیره می‌کنند.

تنظیمات نسخه‌های قبلی هنگام به‌روزرسانی **خودکار منتقل می‌شود**: توکن و کانال فعلی همان کانال بله می‌ماند، تلگرام پیش‌فرض خاموش است، «دسته‌بندی محصولات» به فهرست ترم‌ها می‌رود، حالت تصویرِ عمومی به هر دو کانال کپی می‌شود و قالب متن خالی یعنی همان ساختار پست قبلی.

## پیش‌نیازها

- وردپرس ۵.۸ یا بالاتر، PHP ۷.۴ یا بالاتر
- حداقل یک مطلب منتشرشده از نوع محتوایی که انتخاب می‌کنید (ووکامرس فقط برای ارسال محصول لازم است)
- یک بات و یک کانال در بله و/یا تلگرام (حداقل یکی از این دو)
- برای تلگرام: دسترسی سرور به `api.telegram.org` یا یک پراکسی Bot API

## نصب و به‌روزرسانی

**نصب تازه:** پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← انتخاب فایل zip ← نصب ← فعال‌سازی.

**به‌روزرسانی:** افزونه‌ی قبلی را **حذف نکنید** (حذف، تنظیمات را پاک می‌کند). فقط غیرفعال کنید، بسته‌ی جدید را بارگذاری و فعال کنید. تنظیمات و تاریخچه حفظ می‌شود.

پس از فعال‌سازی، منوی **«ارسال به بله و تلگرام»** در نوار کناری ظاهر می‌شود.

---

## آماده‌سازی بات و کانال

برای هر پیام‌رسانی که می‌خواهید استفاده کنید، همین سه قدم را جدا انجام دهید:

۱. در **بله** (یا **تلگرام**) به `@BotFather` پیام بدهید، بات بسازید و **توکن** را کپی کنید.
۲. بات را به کانال اضافه و **ادمین** کنید (با دسترسی ارسال پیام).
۳. یوزرنیم کانال را یادداشت کنید (مثل `@yourchannel`). برای کانال خصوصی تلگرام، آیدی عددی کانال (مثل `-1001234567890`) را وارد کنید.

توکن بله و توکن تلگرام دو چیز جدا هستند و جای هم کار نمی‌کنند.

## تنظیمات

### کلید اصلی
| گزینه | توضیح |
|---|---|
| فعال باشد | کلید اصلی افزونه. با برداشتن تیک، هیچ پستی به هیچ کانالی نمی‌رود — حتی اگر کانال‌ها روشن باشند. |

### تنظیمات هر کانال (بله و تلگرام، جدا از هم)
| گزینه | توضیح |
|---|---|
| وضعیت کانال | با برداشتن تیک، آن کانال کامل خاموش می‌شود و هیچ درخواستی برایش نمی‌رود. |
| توکن بات | توکن BotFather همان پیام‌رسان. |
| آیدی کانال | یوزرنیم با `@` یا (تلگرام خصوصی) آیدی عددی. |
| نشانی پراکسی API | فقط تلگرام. خالی = `api.telegram.org`. |
| ارسال تصویر | «خودکار» پیشنهاد می‌شود: اول لینک، اگر نشد آپلود مستقیم. برای همین کانال. |
| متن پیام | قالب متن با شورت‌کد. خالی = قالب پیش‌فرض. |
| دکمه‌ی زیر پیام | نمایش/عدم نمایش دکمه و متن دلخواه آن (شورت‌کد هم می‌پذیرد). |

**شورت‌کدهای قالب:**

| شورت‌کد | مقدار |
|---|---|
| `{title}` | عنوان مطلب |
| `{excerpt}` | توضیح کوتاه محصول، یا چکیده/ابتدای متن مطلب |
| `{url}` | نشانی مطلب |
| `{price_block}` | بلوک کامل قیمت و تخفیف (فقط محصول) |
| `{price}` `{price_regular}` `{price_sale}` `{discount}` | اجزای قیمت |
| `{stock}` `{sku}` | موجودی و کد محصول |
| `{categories}` `{type}` | دسته‌بندی‌ها و نام نوع محتوا |
| `{phone}` `{site}` `{date}` | شماره تماس تنظیمات، نام سایت، تاریخ امروز |

قالب پیش‌فرض:

```
🔹 *{title}*

{excerpt}

{price_block}
🔗 {url}
```

- خطی که فقط شورت‌کد داشته باشد و مقدارش خالی باشد (مثل قیمت برای یک نوشته) از پست حذف می‌شود.
- بخش شرطی: `{if:discount}🔥 فقط امروز!{/if:discount}`
- قالب‌بندی مارک‌داون (`*پررنگ*` و `_کج_`) در خودِ قالب کار می‌کند؛ علامت‌های مارک‌داونِ داخل عنوان و متن محصول خودکار خنثی می‌شوند تا پست با خطای `can't parse entities` از بین نرود.

### محتوای پست
| گزینه | توضیح |
|---|---|
| نوع محتوا | از کدام نوع پست انتخاب شود: محصول، نوشته، برگه یا نوع پست سفارشی (از جمله جت‌انجین). خالی = محصول (یا نوشته اگر ووکامرس نباشد). |
| دسته‌بندی و ترم | فقط از ترم‌های انتخابی پست می‌شود. خالی = همه‌ی مطالبِ نوع محتوای انتخاب‌شده. بعد از تغییر نوع محتوا یک بار ذخیره کنید تا فهرست طبقه‌بندی‌ها تازه شود. |
| جلوگیری از تکرار | این تعداد از آخرین مطالبِ پست‌شده دوباره انتخاب نمی‌شوند. ۰ = بدون محدودیت. |
| موجودی | فقط محصولات موجود ارسال شوند. (فقط روی محصول اثر دارد.) |
| قیمت | نمایش یا عدم نمایش قیمت در پست. (فقط برای محصول.) |
| شماره تماس | مقدار شورت‌کد `{phone}`؛ برای محصول بدون قیمت هم در بلوک قیمت می‌آید. |

### زمان‌بندی
| گزینه | توضیح |
|---|---|
| روزهای ارسال | فقط در روزهای تیک‌خورده. هیچ تیکی نزنید = همه‌ی روزها. |
| ساعت ارسال | به وقت تهران. پست در اولین بررسی بعد از این ساعت می‌رود. |
| تلاش مجدد | سقف تلاش در روز، و تعداد تکرار درخواست شبکه در هر تلاش. |

### هشدار خرابی
اگر دو روز پستی ارسال نشود، یک ایمیل هشدار می‌رود (حداکثر روزی یکی). خالی گذاشتن فیلد ایمیل یعنی ارسال به ایمیل مدیر سایت.

## کارت وضعیت سلامت

بالای صفحه‌ی تنظیمات، وضعیت واقعی افزونه را نشان می‌دهد:

- **چرخه‌ی بررسی** — آیا افزونه اصلاً در حال بررسی هست (از هر مسیری).
- **WP-Cron** — آیا زمان‌بندی خود وردپرس سالم است. بلافاصله بعد از نصب «در انتظار اولین اجرا» نشان می‌دهد و تا نیم‌ساعت بعد قضاوت نمی‌کند.
- **ارسال بعدی** — تاریخ و ساعت دقیق پست بعدی به وقت تهران.
- **وضعیت امروز** — ارسال شده یا نه، و چند تلاش انجام شده.

دکمه‌ی **بازسازی زمان‌بندی** رویداد کران را از نو ثبت می‌کند.

روی کارت هر کانال هم نشانِ وضعیت می‌آید: «آماده‌ی ارسال»، «خاموش»، یا «روشن ولی ناقص».

---

## تست

سه دکمه برای تست هست و همه‌شان اول تنظیمات صفحه را ذخیره می‌کنند:

- **تست اتصال** (روی کارت هر کانال): فقط توکن را با `getMe` بررسی می‌کند و نام بات را می‌گوید. هیچ پستی ارسال نمی‌شود.
- **پیش‌نمایش متن** (کنار قالب هر کانال): متن نهایی را با یک مطلب واقعی نشان می‌دهد، بدون ارسال.
- **ارسال تستی** (تک‌کاناله روی هر کارت، یا به همه‌ی کانال‌های فعال از پایین صفحه): همین حالا یک مطلب می‌فرستد و نتیجه‌ی هر کانال را نشان می‌دهد. این ارسال **جای پست خودکار آن روز را نمی‌گیرد**.

اگر کانالی خاموش باشد، دکمه‌های همان کارت کاری نمی‌کنند و علتش را می‌گویند.

## cron سمت سرور (پیشنهاد جدی)

WP-Cron تایمر واقعی نیست و فقط با بازدید سایت اجرا می‌شود. برای ارسال دقیقاً سر ساعت:

۱. در `wp-config.php`:
```php
define('DISABLE_WP_CRON', true);
```

۲. در پنل هاست (cPanel ← Cron Jobs)، هر ۵ دقیقه:
```
*/5 * * * * wget -q -O - https://YOURSITE.com/wp-cron.php?doing_wp_cron >/dev/null 2>&1
```

بدون این کار هم افزونه پست می‌گذارد (از طریق بازدیدهای سایت)، ولی ممکن است چند ده دقیقه دیرتر از ساعت تنظیم‌شده.

## رفع اشکال

| پیام | علت و راه‌حل |
|---|---|
| `chat not found` | یوزرنیم کانال اشتباه است یا بات عضو کانال نیست. |
| `Forbidden` / `bot was blocked` | بات ادمین کانال نیست یا دسترسی ارسال ندارد. |
| `unauthorized` | توکن اشتباه است؛ از BotFather توکن تازه بگیرید. |
| `failed to get HTTP URL content` | پیام‌رسان نتوانست تصویر را از سایت بگیرد. در حالت «خودکار» خودش آپلود مستقیم را امتحان می‌کند؛ اگر تکرار شد، حالت تصویر را روی «همیشه آپلود مستقیم» بگذارید. |
| `cURL error 28` / `Connection timed out` روی تلگرام | سرور سایت به `api.telegram.org` دسترسی ندارد. نشانی یک پراکسی Bot API را در فیلد «نشانی پراکسی API» بگذارید. ارسال به بله از این موضوع مستقل است. |
| پست به بله رفت ولی به تلگرام نه | تاریخچه را ببینید؛ ردیف ناموفق، نام کانال و علت را نشان می‌دهد. |
| `ارسال به ... خاموش است` | تیک «وضعیت کانال» همان کارت را بزنید. |
| `هیچ کانالی فعال و تنظیم‌شده نیست` | حداقل یکی از بله یا تلگرام را فعال کنید و توکن و آیدی کانالش را وارد کنید. |
| پست رفت ولی متن عوض نشد | هر کانال قالب خودش را دارد؛ قالب همان کانال را با «پیش‌نمایش متن» بررسی کنید. |
| `can't parse entities` | نباید رخ دهد (کاراکترها خنثی می‌شوند). اگر دیدید، متن قالب خودتان را بررسی کنید. |
| `ووکامرس فعال نیست` | فقط وقتی رخ می‌دهد که تنها «محصول» را انتخاب کرده باشید؛ ووکامرس را فعال کنید یا نوع محتوای دیگری انتخاب کنید. |
| `هیچ مطلبی با این فیلترها پیدا نشد` | فیلتر نوع محتوا، ترم یا موجودی خیلی محدود است. |
| کارت سلامت قرمز ولی خطایی در تاریخچه نیست | چرخه‌ی بررسی اجرا نشده؛ دکمه‌ی «بازسازی زمان‌بندی» را بزنید و cron سرور را تنظیم کنید. |

## برندینگ (اختیاری)

افزونه به‌صورت پیش‌فرض **هیچ برندی ندارد**؛ نه بنر، نه لوگو، نه لینک تبلیغاتی. اگر آژانس یا فروشنده‌اید و می‌خواهید نام و لوگوی خودتان در پنل بیاید، لازم نیست کد را دست بزنید.

### ساخت پروفایل

یک پوشه با نام برندتان در `branding/` بسازید:

```
branding/
└── my-agency/
    ├── profile.php
    ├── logo.svg
    └── icon.svg
```

`profile.php` فقط یک آرایه برمی‌گرداند:

```php
<?php
defined( 'ABSPATH' ) || exit;

return array(
    'name'  => 'نام آژانس شما',
    'label' => 'افزونه‌ی ارسال روزانه به بله و تلگرام',
    'phone' => '02100000000',
    'site'  => 'https://example.com/',
    'logo'  => 'logo.svg',
    'icon'  => 'icon.svg',
);
```

همه‌ی کلیدها اختیاری‌اند جز `name`. `icon` آیکون منوی پیشخوان است و باید SVG باشد.

### فعال‌کردن

سه راه، به ترتیب اولویت:

```php
// ۱. از طریق کد (بالاترین اولویت)
add_filter( 'dsb_branding', function () {
    return array( 'name' => 'برند من', 'site' => 'https://example.com/' );
} );

// ۲. در wp-config.php
define( 'DSB_BRANDING', 'my-agency' );

// ۳. یا بسته‌ی برنددار را با build.php بسازید (نیازی به تنظیم روی سایت نیست)
```

### ساخت بسته‌های نصب

```
php build.php
```

یک بسته‌ی تمیز و یک بسته به‌ازای هر پروفایل موجود می‌سازد:

```
dist/daily-bale-post-4.2.0.zip            ← بدون هیچ برندی
dist/daily-bale-post-4.2.0-my-agency.zip  ← برنددار، آماده‌ی نصب
```

بسته‌ی برنددار خودش فایل `branding/active.php` را دارد، پس روی سایت مشتری هیچ تنظیم اضافه‌ای لازم نیست.

پوشه‌های برندینگ (جز نمونه‌ی مستندسازی) در `.gitignore` هستند تا برند خصوصی وارد مخزن عمومی نشود.

## برای توسعه‌دهنده

| فیلتر | کاربرد |
|---|---|
| `dsb_branding` | تعیین برندینگ از طریق کد. |
| `dsb_telegram_endpoint` | تغییر نشانی API تلگرام (پراکسی). |
| `dsb_bale_endpoint` | تغییر نشانی API بله. |
| `dsb_available_post_types` | تغییر فهرست نوع محتواهای قابل انتخاب در پنل. |
| `dsb_selector_query_args` | تغییر آرگومان‌های کوئری انتخاب مطلب (مثلاً فیلتر روی فیلدهای جت‌انجین). |
| `dsb_default_template` | تغییر قالب پیش‌فرض متن پیام. |
| `dsb_message_tokens` | افزودن یا تغییر شورت‌کدهای قالب. |

```php
// پراکسی تلگرام
add_filter( 'dsb_telegram_endpoint', function () {
	return 'https://tg-proxy.example.com/bot';
} );

// افزودن شورت‌کد {brand} به قالب
add_filter(
	'dsb_message_tokens',
	function ( $tokens, $post ) {
		$tokens['brand'] = $post ? DSB_Message::escape( (string) get_post_meta( $post->ID, 'brand', true ) ) : '';

		return $tokens;
	},
	10,
	2
);
```
