# افزونه Daily Bale Post

ارسال خودکار روزانه‌ی یک **محصول ووکامرس، نوشته، برگه یا نوع پست سفارشی** (از جمله نوع پست‌های ساخته‌شده با **جت‌انجین**) به کانال **بله** و **تلگرام**، همراه با عکس، قیمت (و تخفیف)، متن و دکمه‌ی مشاهده. تمام تنظیمات از پنل مدیریت وردپرس قابل کنترل است.

**نسخه ۴.۳.۰** — متن پیام قابل ویرایش و تنظیمات مستقل برای هر کانال.

---

## چه چیزی در نسخه ۴.۳ اضافه شد

- **متن پیام قابل ویرایش**: برای هر کانال یک قالب متن جدا هست. با شورت‌کد می‌نویسید و خالی‌گذاشتنش یعنی قالب پیش‌فرض. فهرست شورت‌کدها کنار همان فیلد است و با یک کلیک درج می‌شود.
- **شرط در قالب**: `{if:discount}🔥 فقط امروز!{/if:discount}` ـ یعنی آن بخش فقط وقتی مقدار دارد نمایش داده شود. خطی که فقط شورت‌کدِ خالی داشته باشد (مثل قیمت برای یک نوشته) از پست حذف می‌شود.
- **تنظیمات کامل و مستقل برای هر کانال**: توکن، آیدی کانال، متن پیام، حالت ارسال تصویر، نمایش و متن دکمه — همه برای بله و تلگرام جدا. تنظیم «ارسال تصویر» که قبلاً عمومی بود، به هر کانال منتقل شد (مقدار قبلی‌تان به هر دو کانال کپی می‌شود).
- **کانال خاموش کامل از مدار خارج می‌شود**: برای کانال غیرفعال هیچ کلاینتی ساخته نمی‌شود، پس نه پست خودکار می‌رود، نه ارسال تستی، نه حتی یک درخواست به سرورش. اگر برای کانال خاموش دکمه‌ی تست بزنید، افزونه علتش را می‌گوید.
- **تست اتصال بدون ارسال پست**: دکمه‌ی «تست اتصال» هر کانال، با `getMe` توکن را بررسی می‌کند و نام بات را نشان می‌دهد.
- **پیش‌نمایش متن**: دکمه‌ی «پیش‌نمایش متن» همان پیامی را که با قالب فعلی ساخته می‌شود نشان می‌دهد، بدون ارسال به کانال.
- **ارسال تستی تک‌کاناله**: روی هر کارت، «ارسال تستی فقط به بله / فقط به تلگرام».
- **ذخیره‌ی خودکار قبل از تست**: دکمه‌های تست، پیش‌نمایش و تست اتصال، اول تنظیمات همان صفحه را ذخیره می‌کنند؛ دیگر لازم نیست قبل از هر تست دکمه‌ی ذخیره را بزنید.
- **وضعیت هر کانال در یک نگاه**: روی کارت هر کانال نشانِ «آماده‌ی ارسال»، «خاموش» یا «روشن ولی ناقص» می‌آید و کارت کانال خاموش کم‌رنگ می‌شود.

---

## چه چیزی در نسخه ۴.۲ اضافه شد

- **ارسال نوشته و هر نوع پست سفارشی**: در تنظیمات، فیلد **نوع محتوا** اضافه شده و می‌توانید محصول، نوشته، برگه یا هر نوع پست سفارشی را انتخاب کنید. اگر چند مورد انتخاب کنید، هر روز از میان همه‌ی آن‌ها یکی تصادفی ارسال می‌شود.
- **سازگاری با جت‌انجین**: نوع پست‌های ساخته‌شده با JetEngine (یا هر افزونه‌ی دیگر) چون در وردپرس ثبت می‌شوند، خودشان در فهرست «نوع محتوا» می‌آیند؛ تنظیم جداگانه‌ای لازم نیست.
- **انتخاب دسته و ترم برای هر نوع محتوا**: فیلد **دسته‌بندی و ترم**، طبقه‌بندی‌های همان نوع محتواها را گروه‌بندی‌شده نشان می‌دهد (دسته‌ی محصول، دسته‌ی نوشته، طبقه‌بندی‌های جت‌انجین و ...). انتخاب چند ترم از چند طبقه‌بندی با رابطه‌ی «یا» اعمال می‌شود.
- **پیام مناسب هر نوع محتوا**: بخش قیمت و تخفیف فقط برای محصول ووکامرس ساخته می‌شود؛ برای نوشته و نوع پست سفارشی، چکیده (و اگر نبود، ابتدای متن) فرستاده می‌شود و متن دکمه «مشاهده مطلب» است.
- **فیلتر موجودی فقط برای محصول**: در حالت ترکیبی (محصول + نوشته)، محصول ناموجود رد می‌شود ولی نوشته‌ها حذف نمی‌شوند.
- **مهاجرت خودکار**: «دسته‌بندی محصولات»ی که قبلاً انتخاب کرده بودید به فهرست ترم‌ها منتقل می‌شود و نوع محتوا روی «محصول» می‌ماند؛ یعنی رفتار فعلی سایت عوض نمی‌شود.

---

## چه چیزی در نسخه ۴.۱ اضافه شد

- **ارسال به تلگرام**: همان پست روزانه، هم‌زمان به کانال بله و کانال تلگرام می‌رود. می‌توانید هر کدام را جداگانه خاموش یا روشن کنید.
- **کلاینت مشترک**: بله و تلگرام هر دو از قرارداد Bot API استفاده می‌کنند، پس همان زنجیره‌ی مقاوم ارسال تصویر (لینک ← آپلود مستقیم ← فقط متن)، کوتاه‌کردن کپشن، خنثی‌سازی مارک‌داون و تلاش مجدد، برای تلگرام هم اجرا می‌شود.
- **نشانی پراکسی برای تلگرام**: چون سرورهای داخل ایران معمولاً به `api.telegram.org` دسترسی ندارند، می‌توانید نشانی یک پراکسی Bot API را در تنظیمات وارد کنید (یا با فیلتر `dsb_telegram_endpoint` عوضش کنید).
- **ارسال نیمه‌موفق**: اگر یکی از کانال‌ها جواب بدهد و دیگری نه، پست روی کانال سالم می‌رود، خطای کانال دیگر جداگانه در تاریخچه ثبت می‌شود و پست آن روز سوخته حساب نمی‌شود.
- تنظیمات نسخه‌های قبلی دست‌نخورده می‌ماند؛ توکن و کانال فعلی همان کانال بله باقی می‌ماند و تلگرام به‌صورت پیش‌فرض خاموش است.

---

## چه چیزی در نسخه ۴ عوض شد

نسخه‌های قبلی یک رویداد روزانه‌ی تک‌شلیکی در WP-Cron ثبت می‌کردند. اگر آن رویداد از صف وردپرس گم می‌شد یا WP-Cron روی سایت اجرا نمی‌شد، افزونه **بی‌صدا و برای همیشه** از کار می‌افتاد تا وقتی کسی وارد تنظیمات می‌شد و دکمه‌ی ذخیره را می‌زد. نسخه‌ی ۴ این مسیر را از پایه عوض کرده است:

| مشکل نسخه ۳ | راه‌حل نسخه ۴ |
|---|---|
| رویداد کران گم می‌شد و برنمی‌گشت | هر بار بارگذاری وردپرس بررسی می‌شود؛ اگر رویداد نباشد خودش دوباره ثبت می‌شود |
| اگر WP-Cron اجرا نمی‌شد، هیچ پستی نمی‌رفت | بازدیدهای عادی سایت هم همان بررسی را انجام می‌دهند (حداکثر هر ۵ دقیقه یک بار) |
| تأخیر کران تا بعد از نیمه‌شب، پست آن روز را می‌سوزاند | معیار «امروز پست رفته یا نه» است، نه «الان دقیقاً ساعت ارسال است» |
| یک خطای گذرای شبکه = یک روز بدون پست | تا ۳ بار در روز با فاصله‌ی ۱۵ دقیقه تلاش می‌شود |
| خطای `failed to get HTTP URL content` پست را از بین می‌برد | اگر بله نتواند لینک تصویر را بگیرد، فایل مستقیماً آپلود می‌شود؛ در بدترین حالت پست بدون عکس می‌رود |
| نام محصول با `_` یا `*` می‌توانست کل پست را خراب کند | کاراکترهای مارک‌داون در متن پویا خنثی می‌شوند |
| کپشن بلند باعث رد شدن پست می‌شد | متن به حد مجاز بله کوتاه می‌شود |
| چند درخواست هم‌زمان چند پست پشت‌سرهم می‌فرستادند | قفل اتمیک + علامت «امروز ارسال شد» |
| خرابی هفته‌ها بی‌سروصدا می‌ماند | کارت وضعیت سلامت + ایمیل هشدار |

تنظیمات نسخه‌ی ۳ هنگام به‌روزرسانی **خودکار منتقل می‌شود**؛ نیازی به وارد کردن دوباره‌ی توکن نیست.

## پیش‌نیازها

- وردپرس ۵.۸ یا بالاتر، PHP ۷.۴ یا بالاتر
- حداقل یک مطلب منتشرشده از نوع محتوایی که انتخاب می‌کنید (ووکامرس فقط برای ارسال محصول لازم است)
- یک بات و یک کانال در بله و/یا تلگرام (حداقل یکی از این دو)
- برای تلگرام: دسترسی سرور به `api.telegram.org` یا یک پراکسی Bot API

---

## نصب و به‌روزرسانی

**نصب تازه:** پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← انتخاب `daily-bale-post.zip` ← نصب ← فعال‌سازی.

**به‌روزرسانی از نسخه ۳:** افزونه‌ی قبلی را **حذف نکنید** (حذف، تنظیمات را پاک می‌کند). فقط پوشه‌ی افزونه را با نسخه‌ی جدید جایگزین کنید، یا افزونه را غیرفعال و نسخه‌ی جدید را بارگذاری و فعال کنید. تنظیمات و تاریخچه حفظ می‌شود.

پس از فعال‌سازی، منوی **«ارسال به بله»** در نوار کناری ظاهر می‌شود.

---

## آماده‌سازی بات و کانال

برای هر پیام‌رسانی که می‌خواهید استفاده کنید، همین سه قدم را جدا انجام دهید:

۱. در **بله** (یا **تلگرام**) به `@BotFather` پیام بدهید، بات بسازید و **توکن** را کپی کنید.
۲. بات را به کانال اضافه و **ادمین** کنید (با دسترسی ارسال پیام).
۳. یوزرنیم کانال را یادداشت کنید (مثل `@yourchannel`). برای کانال خصوصی تلگرام، آیدی عددی کانال (مثل `-1001234567890`) را وارد کنید.

توکن بله و توکن تلگرام دو چیز جدا هستند و جای هم کار نمی‌کنند.

## تنظیمات

### اتصال به بله
| گزینه | توضیح |
|---|---|
| فعال باشد | کلید اصلی افزونه. با برداشتن تیک، هیچ پستی به هیچ کانالی نمی‌رود. |
| ارسال به بله | ارسال پست روزانه به کانال بله. |
| توکن بات بله | توکن گرفته‌شده از BotFather در بله. |
| آیدی کانال | یوزرنیم کانال بله با `@`. |

### اتصال به تلگرام
| گزینه | توضیح |
|---|---|
| ارسال به تلگرام | همان پست روزانه به کانال تلگرام هم می‌رود. پیش‌فرض: خاموش. |
| توکن بات تلگرام | توکن گرفته‌شده از BotFather در تلگرام. |
| آیدی کانال تلگرام | یوزرنیم کانال با `@` یا آیدی عددی کانال خصوصی. |
| نشانی پراکسی API | خالی = `api.telegram.org`. اگر سرور در ایران است، نشانی پراکسی Bot API خود را بگذارید. |

### تنظیمات هر کانال (بله و تلگرام، جدا از هم)
| گزینه | توضیح |
|---|---|
| وضعیت کانال | با برداشتن تیک، آن کانال کامل خاموش می‌شود و هیچ درخواستی برایش نمی‌رود. |
| توکن بات | توکن BotFather همان پیام‌رسان. |
| آیدی کانال | یوزرنیم با `@` یا (تلگرام خصوصی) آیدی عددی. |
| نشانی پراکسی API | فقط تلگرام. خالی = `api.telegram.org`. |
| ارسال تصویر | «خودکار» پیشنهاد می‌شود: اول لینک، اگر نشد آپلود مستقیم. برای همین کانال. |
| متن پیام | قالب متن با شورت‌کد. خالی = قالب پیش‌فرض. |
| دکمه‌ی زیر پیام | نمایش/عدم نمایش دکمه و متن دلخواه آن (شورت‌کد هم می‌پذیرد). |

**شورت‌کدهای قالب:** `{title}` `{excerpt}` `{url}` `{price_block}` `{price}` `{price_regular}` `{price_sale}` `{discount}` `{stock}` `{sku}` `{categories}` `{type}` `{phone}` `{site}` `{date}`

قالب پیش‌فرض:

```
🔹 *{title}*

{excerpt}

{price_block}
🔗 {url}
```

قالب‌بندی مارک‌داون (`*پررنگ*` و `_کج_`) در خودِ قالب کار می‌کند؛ علامت‌های مارک‌داونِ داخل عنوان و متن محصول خودکار خنثی می‌شوند تا پست با خطای `can't parse entities` از بین نرود.

### محتوای پست
| گزینه | توضیح |
|---|---|
| نوع محتوا | از کدام نوع پست انتخاب شود: محصول، نوشته، برگه یا نوع پست سفارشی (از جمله جت‌انجین). خالی = محصول (یا نوشته اگر ووکامرس نباشد). |
| دسته‌بندی و ترم | فقط از ترم‌های انتخابی پست می‌شود. خالی = همه‌ی مطالبِ نوع محتوای انتخاب‌شده. بعد از تغییر نوع محتوا یک بار ذخیره کنید تا فهرست طبقه‌بندی‌ها تازه شود. |
| جلوگیری از تکرار | این تعداد از آخرین محصولات دوباره انتخاب نمی‌شوند. ۰ = بدون محدودیت. |
| موجودی | فقط محصولات موجود ارسال شوند. (فقط روی محصول اثر دارد.) |
| قیمت | نمایش یا عدم نمایش قیمت در پست. (فقط برای محصول.) |
| شماره تماس | مقدار شورت‌کد `{phone}`؛ برای محصول بدون قیمت هم در بلوک قیمت می‌آید. |

### زمان‌بندی
| گزینه | توضیح |
|---|---|
| روزهای ارسال | فقط در روزهای تیک‌خورده. هیچ تیکی نزنید = همه‌ی روزها. |
| ساعت ارسال | به وقت تهران. پست در اولین بررسی بعد از این ساعت می‌رود. |
| تلاش مجدد | سقف تلاش در روز، و تعداد تکرار درخواست شبکه در هر تلاش. |

### هشدار خرابی
اگر دو روز پستی ارسال نشود، یک ایمیل هشدار می‌رود (حداکثر روزی یکی). خالی گذاشتن فیلد ایمیل یعنی ارسال به ایمیل مدیر سایت.

## کارت وضعیت سلامت

بالای صفحه‌ی تنظیمات، وضعیت واقعی افزونه را نشان می‌دهد:

- **چرخه‌ی بررسی** — آیا افزونه اصلاً در حال بررسی هست (از هر مسیری).
- **WP-Cron** — آیا زمان‌بندی خود وردپرس سالم است. بلافاصله بعد از نصب «در انتظار اولین اجرا» نشان می‌دهد و تا نیم‌ساعت بعد قضاوت نمی‌کند. اگر «اجرا نمی‌شود» باشد، افزونه با پشتیبانِ مبتنی بر بازدید کار می‌کند ولی بهتر است cron سرور تنظیم شود.
- **ارسال بعدی** — تاریخ و ساعت دقیق پست بعدی به وقت تهران.
- **وضعیت امروز** — ارسال شده یا نه، و چند تلاش انجام شده.

دکمه‌ی **بازسازی زمان‌بندی** رویداد کران را از نو ثبت می‌کند.

---

## تست

سه دکمه برای تست هست و همه‌شان اول تنظیمات صفحه را ذخیره می‌کنند:

- **تست اتصال** (روی کارت هر کانال): فقط توکن را با `getMe` بررسی می‌کند و نام بات را می‌گوید. هیچ پستی ارسال نمی‌شود.
- **پیش‌نمایش متن** (کنار قالب هر کانال): متن نهایی را با یک مطلب واقعی نشان می‌دهد، بدون ارسال.
- **ارسال تستی** (تک‌کاناله روی هر کارت، یا به همه‌ی کانال‌های فعال از پایین صفحه): همین حالا یک مطلب می‌فرستد و نتیجه‌ی هر کانال را نشان می‌دهد. این ارسال **جای پست خودکار آن روز را نمی‌گیرد**.

اگر کانالی خاموش باشد، دکمه‌های همان کارت کاری نمی‌کنند و علتش را می‌گویند.

## cron سمت سرور (پیشنهاد جدی)

WP-Cron تایمر واقعی نیست و فقط با بازدید سایت اجرا می‌شود. برای ارسال دقیقاً سر ساعت:

۱. در `wp-config.php`:
```php
define('DISABLE_WP_CRON', true);
```

۲. در پنل هاست (cPanel ← Cron Jobs)، هر ۵ دقیقه:
```
*/5 * * * * wget -q -O - https://YOURSITE.com/wp-cron.php?doing_wp_cron >/dev/null 2>&1
```

بدون این کار هم افزونه پست می‌گذارد (از طریق بازدیدهای سایت)، ولی ممکن است چند ده دقیقه دیرتر از ساعت تنظیم‌شده.

## رفع اشکال

| پیام | علت و راه‌حل |
|---|---|
| `chat not found` | یوزرنیم کانال اشتباه است یا بات عضو کانال نیست. |
| `Forbidden` / `bot was blocked` | بات ادمین کانال نیست یا دسترسی ارسال ندارد. |
| `unauthorized` | توکن اشتباه است؛ از BotFather توکن تازه بگیرید. |
| `failed to get HTTP URL content` | پیام‌رسان نتوانست تصویر را از سایت بگیرد. در حالت «خودکار» خودش آپلود مستقیم را امتحان می‌کند؛ اگر تکرار شد، حالت تصویر را روی «همیشه آپلود مستقیم» بگذارید. |
| `cURL error 28` / `Connection timed out` روی تلگرام | سرور سایت به `api.telegram.org` دسترسی ندارد (معمولاً روی هاست‌های ایران). نشانی یک پراکسی Bot API را در فیلد «نشانی پراکسی API» بگذارید. ارسال به بله از این موضوع مستقل است. |
| پست به بله رفت ولی به تلگرام نه | تاریخچه را ببینید؛ ردیف ناموفق، نام کانال و علت را نشان می‌دهد. توکن، ادمین بودن بات و دسترسی شبکه را بررسی کنید. |
| `can't parse entities` | نباید رخ دهد (کاراکترها خنثی می‌شوند). اگر دیدید، متن توضیح کوتاه محصول را بررسی کنید. |
| `توکن یا آیدی کانال تنظیم نشده` | فیلدهای توکن و کانال را پر کنید. |
| `هیچ کانالی فعال و تنظیم‌شده نیست` | حداقل یکی از بله یا تلگرام را فعال کنید و توکن و آیدی کانالش را وارد کنید. |
| `ارسال به ... خاموش است` | تیک «وضعیت کانال» همان کارت را بزنید. |
| پست رفت ولی متن عوض نشد | قالب همان کانال را ویرایش کرده‌اید؟ هر کانال قالب خودش را دارد. با «پیش‌نمایش متن» بررسی کنید. |
| `ووکامرس فعال نیست` | فقط وقتی رخ می‌دهد که تنها «محصول» را انتخاب کرده باشید؛ ووکامرس را فعال کنید یا نوع محتوای دیگری انتخاب کنید. |
| `هیچ مطلبی با این فیلترها پیدا نشد` | فیلتر نوع محتوا، ترم یا موجودی خیلی محدود است. |
| کارت سلامت قرمز ولی خطایی در تاریخچه نیست | چرخه‌ی بررسی اجرا نشده؛ دکمه‌ی «بازسازی زمان‌بندی» را بزنید و cron سرور را تنظیم کنید. |

## برای توسعه‌دهنده

| فیلتر | کاربرد |
|---|---|
| `dsb_telegram_endpoint` | تغییر نشانی API تلگرام (پراکسی) در کد، به‌جای فیلد تنظیمات. |
| `dsb_bale_endpoint` | تغییر نشانی API بله. |
| `dsb_available_post_types` | تغییر فهرست نوع محتواهای قابل انتخاب در پنل. |
| `dsb_selector_query_args` | تغییر آرگومان‌های کوئری انتخاب مطلب (مثلاً فیلتر روی فیلدهای جت‌انجین). |
| `dsb_default_template` | تغییر قالب پیش‌فرض متن پیام. |
| `dsb_message_tokens` | افزودن یا تغییر شورت‌کدهای قالب (مثلاً یک متافیلد جت‌انجین). |

```php
add_filter( 'dsb_telegram_endpoint', function () {
	return 'https://tg-proxy.example.com/bot';
} );

// افزودن شورت‌کد {brand} به قالب.
add_filter(
	'dsb_message_tokens',
	function ( $tokens, $post ) {
		$tokens['brand'] = $post ? DSB_Message::escape( (string) get_post_meta( $post->ID, 'brand', true ) ) : '';

		return $tokens;
	},
	10,
	2
);
```
