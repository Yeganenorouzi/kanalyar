# کانال‌یار — انتشار خودکار محتوای وردپرس

محتوای سایتت را خودکار در کانال‌های **بله** و **تلگرام** منتشر کن: محصولات ووکامرس، نوشته‌ها، برگه‌ها یا هر نوع محتوای دیگری. همراه با عکس شاخص، قیمت و تخفیف (برای محصولات)، خلاصه‌ی مطلب و دکمه‌ی لینک.

**نسخه ۶.۰.۰** — انتشار فوری، قالب پیام سفارشی، هشتگ، ایتا.

---

## در یک نگاه

افزونه سه مفهوم دارد:

| مفهوم | یعنی چه |
|---|---|
| **مقصد** | یک کانال بله یا تلگرام، با توکن بات خودش. هر تعداد که بخواهید. |
| **قانون انتشار** | چه محتوایی، به کدام مقصدها، با چه ترتیبی، چه روزها و چه ساعتی. |
| **تنظیمات کلی** | کلید اصلی، شماره تماس، هشدار خرابی. |

مثال: قانون «محصولات» هر روز ۱۰:۴۵ یک محصول تصادفی به کانال بله و تلگرام فروشگاه می‌فرستد؛ قانون «مقالات» شنبه و سه‌شنبه ۱۸:۰۰ جدیدترین مقاله‌ی ارسال‌نشده را فقط به کانال بلاگ می‌فرستد.

## چه چیزی در نسخه ۶ تازه است

| نسخه ۵ | نسخه ۶ |
|---|---|
| فقط انتشار زمان‌بندی‌شده | **انتشار فوری** به‌محض منتشر شدن مطلب تازه |
| قالب پیام ثابت در کد | **قالب سفارشی** با ۱۷ جای‌نشان |
| بدون هشتگ | هشتگ خودکار از برچسب‌ها و دسته‌ها |
| بله و تلگرام | بله، تلگرام و **ایتا** |
| بدون کنترل اعلان | ارسال بی‌صدا و سنجاق‌کردن پیام |
| فقط از پنل افزونه | **جعبه‌ی ارسال در صفحه‌ی ویرایش** هر مطلب |
| قیمت محصول ساده | پشتیبانی از بازه‌ی قیمت محصولات متغیر |

افزونه در این نسخه از `Daily Bale Post` به **کانال‌یار** تغییر نام داد. همه‌ی کلیدهای دیتابیس دست‌نخورده ماندند، پس سایت‌های فعلی تنظیماتشان را از دست نمی‌دهند.

تنظیمات نسخه‌های ۳ و ۴ هنگام به‌روزرسانی **خودکار منتقل می‌شوند**: توکن و کانال قبلی به یک مقصد تبدیل می‌شوند و تنظیمات محتوا و زمان به یک قانون.

---

## ⚠️ به‌روزرسانی از نسخه‌های قبلی

نام پوشه‌ی افزونه از `daily-bale-post` به `kanalyar` تغییر کرده، پس وردپرس آن را یک افزونه‌ی تازه می‌بیند. امن‌ترین مسیر:

۱. در پیشخوان، افزونه‌ی قدیمی را **غیرفعال** کنید (غیرفعال‌کردن هیچ داده‌ای را پاک نمی‌کند).
۲. بسته‌ی `kanalyar.zip` را بارگذاری و فعال کنید. همه‌ی تنظیمات، مقصدها، قوانین و تاریخچه سر جایشان هستند.
۳. پوشه‌ی قدیمی `wp-content/plugins/daily-bale-post` را از **فایل‌منیجر هاست** حذف کنید.

> **دکمه‌ی «حذف» وردپرس را روی افزونه‌ی قدیمی نزنید.** آن دکمه فایل `uninstall.php` نسخه‌ی قدیمی را اجرا می‌کند و همه‌ی تنظیمات مشترک را پاک می‌کند. حذف از طریق فایل‌منیجر این اتفاق را نمی‌اندازد.
>
> نسخه ۶ به بعد این تله را ندارد: `uninstall.php` جدید اگر نسخه‌ی دیگری از افزونه را روی سایت ببیند، داده‌ها را پاک نمی‌کند.

## نصب و به‌روزرسانی

**نصب تازه:** پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← نصب ← فعال‌سازی.

**به‌روزرسانی:** افزونه‌ی قبلی را **حذف نکنید** (حذف، تنظیمات را پاک می‌کند). افزونه را غیرفعال کنید، نسخه‌ی جدید را بارگذاری و فعال کنید. تنظیمات و تاریخچه حفظ می‌شود.

پس از فعال‌سازی، منوی **«انتشار خودکار»** در نوار کناری ظاهر می‌شود.

---

## گام اول: ساخت بات

**بله:** به `@BotFather` در بله پیام بدهید، بات بسازید، توکن را کپی کنید، بات را به کانال اضافه و **ادمین** کنید.

**تلگرام:** همین مراحل با `@BotFather` تلگرام.

**ایتا:** توکن را از بخش API در [eitaayar.ir](https://eitaayar.ir) بگیرید. این توکن با توکن BotFather فرق دارد.

> API ایتا فقط ارسال است: دکمه‌ی شیشه‌ای و قالب‌بندی مارک‌داون ندارد. افزونه خودش این را تشخیص می‌دهد، متن ساده می‌فرستد و نشانی مطلب را در خود متن می‌گذارد. تصویر هم همیشه مستقیم آپلود می‌شود.

> **توجه درباره‌ی تلگرام:** اگر سرور سایت در ایران باشد، معمولاً دسترسی مستقیم به `api.telegram.org` بسته است و ارسال با خطای شبکه شکست می‌خورد. در این حالت باید یک پراکسی سمت سرور داشته باشید و نشانی API را عوض کنید:
>
> ```php
> add_filter( 'ky_telegram_endpoint', function () {
>     return 'https://your-proxy.example/bot';
> } );
> ```

## گام سوم: ساخت قانون انتشار

تب **قوانین انتشار** ← افزودن قانون.

### چه محتوایی

| گزینه | توضیح |
|---|---|
| نوع محتوا | محصول، نوشته، برگه یا هر نوع عمومی دیگر. چندتایی با Ctrl. |
| هشتگ | ساخت خودکار هشتگ از برچسب‌ها، دسته‌ها، یا هر دو. |
| بی‌صدا / سنجاق | ارسال بدون اعلان، و سنجاق‌کردن پیام در کانال. |
| دسته‌بندی | فیلتر بر اساس دسته یا برچسب. خالی = همه. |
| ترتیب انتخاب | تصادفی، جدیدترینِ ارسال‌نشده، یا قدیمی‌ترینِ ارسال‌نشده. |
| خلاصه | توضیح کوتاه محصول یا خلاصه‌ی نوشته در پست بیاید. |
| قیمت | فقط روی محصولات اثر دارد. |
| فقط موجود | محصولات ناموجود رد می‌شوند. |

**کدام ترتیب را انتخاب کنم؟** برای کاتالوگ محصولات **تصادفی** مناسب است، چون محصولات تاریخ مصرف ندارند. برای بلاگ و اخبار **جدیدترینِ ارسال‌نشده**، چون انتشار تصادفیِ نوشته‌ی دو سال پیش به‌عنوان مطلب تازه عجیب است. در حالت‌های ترتیبی هر مطلب فقط یک‌بار ارسال می‌شود و وقتی همه رفتند، قانون متوقف می‌شود تا محتوای تازه منتشر کنید.

### چه وقت اجرا شود

| محرک | رفتار |
|---|---|
| **زمان‌بندی** | هر روز سر ساعت، یک مطلب از مجموعه انتخاب و ارسال می‌شود. |
| **هنگام انتشار** | به‌محض منتشر شدن مطلب تازه، فوری ارسال می‌شود. مناسب بلاگ و اخبار. |
| **هر دو** | هم فوری هنگام انتشار، هم چکاندن روزانه از آرشیو. |

در حالت «هنگام انتشار»، ارسال بعد از بسته‌شدن پاسخ انجام می‌شود تا نویسنده منتظر نماند. هر مطلب با هر قانون فقط یک‌بار خودکار ارسال می‌شود.

### قالب پیام

قالب را خالی بگذارید تا قالب پیش‌فرض استفاده شود، یا خودتان بنویسید:

```
🔹 *{title}*

{excerpt}

{price}
🔗 {link}

{hashtags}
```

جای‌نشان‌های موجود:

| جای‌نشان | مقدار |
|---|---|
| `{title}` | عنوان مطلب |
| `{excerpt}` | خلاصه یا توضیح کوتاه |
| `{link}` | نشانی مطلب |
| `{price}` | بخش کامل قیمت و تخفیف (فقط محصول) |
| `{price_amount}` | فقط عدد قیمت فعلی |
| `{regular_price}` / `{sale_price}` / `{discount}` | قیمت بدون تخفیف، با تخفیف، درصد |
| `{sku}` / `{stock}` | کد محصول، وضعیت موجودی |
| `{categories}` / `{tags}` | دسته‌ها و برچسب‌ها با ویرگول |
| `{hashtags}` | برچسب‌ها و دسته‌ها به شکل هشتگ |
| `{author}` / `{date}` / `{site}` / `{phone}` | نویسنده، تاریخ، نام سایت، شماره تماس |

جای‌نشان خالی خط سفید جا نمی‌گذارد. برای پیام‌رسان‌هایی که قالب‌بندی ندارند (ایتا) همین قالب به‌صورت متن ساده رندر می‌شود.

### به کدام کانال‌ها

هر تعداد مقصد را تیک بزنید. یک مطلب به همه‌ی مقصدهای تیک‌خورده می‌رود. اگر یک مقصد شکست بخورد، بقیه ارسال می‌شوند و فقط آن یکی در تاریخچه قرمز می‌شود.

### چه زمانی

روزهای هفته، ساعت (به وقت تهران)، سقف تلاش در روز و حالت ارسال تصویر.

دکمه‌ی **ارسال تستی** بدون توجه به روز و ساعت همین حالا یک مطلب می‌فرستد و **جای پست خودکار آن روز را نمی‌گیرد**.

دکمه‌ی **شروع دوباره** تاریخچه‌ی ارسال آن قانون را پاک می‌کند تا همه‌ی مطالب دوباره واجد شرایط شوند.

---

## جعبه‌ی ارسال در صفحه‌ی ویرایش

در صفحه‌ی ویرایش هر مطلب، جعبه‌ای در ستون کناری نشان می‌دهد کدام قوانین با آن مطلب می‌خوانند، به کدام کانال‌ها می‌رود، و آیا قبلاً ارسال شده یا نه. دکمه‌ی **ارسال همین حالا** مطلب را فوری به همه‌ی آن قوانین می‌فرستد.

---

## کارت وضعیت سلامت

بالای همه‌ی تب‌ها، وضعیت واقعی افزونه را نشان می‌دهد:

- **قوانین فعال** — چند قانون از چند قانون آماده‌ی اجرا هستند.
- **چرخه‌ی بررسی** — آیا افزونه اصلاً در حال بررسی هست (از هر مسیری).
- **WP-Cron** — آیا زمان‌بندی خود وردپرس سالم است. بلافاصله بعد از نصب «در انتظار اولین اجرا» نشان می‌دهد و تا نیم‌ساعت قضاوت نمی‌کند.

دکمه‌ی **بازسازی زمان‌بندی** رویداد کران را از نو ثبت می‌کند.

---

## چرا این افزونه بی‌صدا از کار نمی‌افتد

نسخه‌های قدیمی یک رویداد روزانه‌ی تک‌شلیکی در WP-Cron ثبت می‌کردند. اگر آن رویداد گم می‌شد یا WP-Cron اجرا نمی‌شد، افزونه **بی‌صدا و برای همیشه** متوقف می‌شد. نسخه‌های ۴ و ۵ این را حل کرده‌اند:

- **خودترمیمی** — هر بار بارگذاری وردپرس بررسی می‌شود؛ اگر رویداد کران نباشد، دوباره ثبت می‌شود.
- **پشتیبان مستقل** — اگر WP-Cron کار نکند، بازدیدهای عادی سایت همان بررسی را انجام می‌دهند (حداکثر هر ۵ دقیقه). پاسخ بازدیدکننده قبل از ارسال بسته می‌شود تا کسی منتظر نماند.
- **معیار درست** — سؤال «امروز پست این قانون رفته یا نه» است، نه «الان دقیقاً ساعت ارسال است». تأخیر کران دیگر پست آن روز را نمی‌سوزاند.
- **تلاش مجدد** — خطای گذرا تا ۳ بار در روز با فاصله‌ی ۱۵ دقیقه تکرار می‌شود.
- **قفل اتمیک** — چند درخواست هم‌زمان نمی‌توانند پست تکراری بفرستند.
- **هشدار** — اگر دو روز هیچ پستی نرود، ایمیل هشدار می‌رود.

## cron سمت سرور (پیشنهاد جدی)

WP-Cron تایمر واقعی نیست و فقط با بازدید سایت اجرا می‌شود. برای ارسال دقیقاً سر ساعت:

۱. در `wp-config.php`:

```php
define('DISABLE_WP_CRON', true);
```

۲. در پنل هاست (cPanel ← Cron Jobs)، هر ۵ دقیقه:

```
*/5 * * * * wget -q -O - https://YOURSITE.com/wp-cron.php?doing_wp_cron >/dev/null 2>&1
```

بدون این کار هم افزونه پست می‌گذارد (از طریق بازدیدهای سایت)، ولی ممکن است چند ده دقیقه دیرتر.

## رفع اشکال

| پیام | علت و راه‌حل |
|---|---|
| `chat not found` | آیدی کانال اشتباه است یا بات عضو کانال نیست. |
| `Forbidden` / `bot was blocked` | بات ادمین کانال نیست یا دسترسی ارسال ندارد. |
| `unauthorized` | توکن اشتباه است. با دکمه‌ی «تست اتصال» بررسی کنید. |
| `failed to get HTTP URL content` | سرور پیام‌رسان نتوانست تصویر را از سایت بگیرد. در حالت «خودکار» خودش آپلود مستقیم را امتحان می‌کند؛ اگر تکرار شد، حالت تصویر را روی «همیشه آپلود مستقیم» بگذارید. |
| خطای شبکه روی تلگرام | سرور ایران به تلگرام دسترسی ندارد. فیلتر `ky_telegram_endpoint` را با پراکسی تنظیم کنید. |
| `همه‌ی مطالب این قانون قبلاً ارسال شده‌اند` | راهبرد ترتیبی به انتهای محتوا رسیده. محتوای تازه منتشر کنید یا «شروع دوباره» را بزنید. |
| `هیچ مطلبی با این فیلترها پیدا نشد` | فیلتر دسته‌بندی یا موجودی خیلی محدود است. |
| کارت سلامت قرمز ولی خطایی در تاریخچه نیست | چرخه‌ی بررسی اجرا نشده؛ «بازسازی زمان‌بندی» را بزنید و cron سرور را تنظیم کنید. |

## قلاب‌های توسعه

```php
// تغییر نشانی API تلگرام (پراکسی)
add_filter( 'ky_telegram_endpoint', fn() => 'https://proxy.example/bot' );

// تغییر نشانی API ایتا
add_filter( 'ky_eitaa_endpoint', fn() => 'https://eitaayar.ir/api/' );

// محدودکردن نوع‌های محتوای قابل انتشار
add_filter( 'ky_available_post_types', function ( $types ) {
    unset( $types['page'] );
    return $types;
} );

// برندینگ از طریق کد
add_filter( 'ky_branding', fn() => array(
    'name' => 'برند من',
    'site' => 'https://example.com/',
) );
```

## برندینگ (اختیاری)

افزونه به‌صورت پیش‌فرض **هیچ برندی ندارد**؛ نه بنر، نه لوگو، نه لینک تبلیغاتی. اگر آژانس یا فروشنده‌اید و می‌خواهید نام و لوگوی خودتان در پنل بیاید، لازم نیست کد را دست بزنید.

### ساخت پروفایل

پوشه‌ی `branding/example/` را کپی کنید و نام برندتان را روی کپی بگذارید:

```
branding/
├── example/          ← نمونه‌ی مستندسازی
└── my-agency/        ← برند شما (در .gitignore است)
    ├── profile.php
    ├── logo.svg
    └── icon.svg
```

پوشه‌های برندینگ جز `example/` در `.gitignore` هستند، تا برند خصوصی‌تان وارد مخزن عمومی نشود.

### فعال‌کردن

سه راه، به ترتیب اولویت:

```php
// ۱. از طریق کد (بالاترین اولویت)
add_filter( 'ky_branding', fn() => array( 'name' => 'برند من' ) );

// ۲. در wp-config.php
define( 'KY_BRANDING', 'my-agency' );

// ۳. یا بسته‌ی برنددار را با build.php بسازید
```

### ساخت بسته‌های نصب

```
php build.php
```

یک بسته‌ی تمیز و یک بسته به‌ازای هر پروفایل می‌سازد. بسته‌ی برنددار خودش `branding/active.php` را دارد، پس روی سایت مشتری هیچ تنظیم اضافه‌ای لازم نیست.
